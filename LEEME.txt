Editor de Dashboards - version web (replica de la plantilla Dashboard v3 de LukeS7)

ACTUALIZAR TU REPO jaz206/editor-cartas
1. Borra los archivos antiguos del repo (index.html y los .png sueltos).
2. Sube el contenido de este zip tal cual: index.html y la carpeta assets/.
3. Vercel vuelve a desplegar solo al hacer commit.

LOGO POR DEFECTO (opcional)
Si guardas tu logo como  assets/logo_default.png  (PNG transparente),
el editor lo pone automaticamente en el reverso al abrirse.

Uso personal y no comercial. Credito de la plantilla: LukeS7 (BoardGameGeek).

IMAGENES DESDE GOOGLE DRIVE
La carpeta api/ contiene img.js: Vercel la publica como /api/img y sirve las
imagenes de Drive desde tu propio dominio para poder exportarlas e imprimirlas.
Cada archivo de Drive debe estar compartido como "cualquier persona con el enlace".

AREA PRIVADA (admin.html)
Pagina solo para el dueño: tu-web.vercel.app/admin.html
Permite ver que falta (imagenes, habilidades, traducciones), corregir textos EN/ES,
subir imagenes de personajes, añadir/eliminar personajes y cambiar el logo por defecto.
Al pulsar "Publicar cambios" se hace un commit en este repositorio y Vercel redespliega.
Necesita dos variables de entorno en Vercel (Settings > Environment Variables):
  ADMIN_PASSWORD  la contraseña que quieras
  GITHUB_TOKEN    token "fine-grained" de GitHub, solo para jaz206/editor-cartas,
                  con permiso Contents: Read and write
Despues de añadirlas, haz "Redeploy" en Vercel.
